# 施工影像 AI 复核演示

用途：施工照片/短视频先由专用模型框出装备，再选择可疑头部交给本地视觉语言模型提供第二意见；巡检人员看原图和模型分歧，一起导出证据。复用SiteWatch完整应用、固定YOLO权重与Qwen官方Gradio接口。检测在CPU、局部复核在本机GPU执行。

## 两分钟演示顺序

页面采用水电一局品牌标识，默认“清晰演示素材”。先选“高清近景：单人安全帽”或“双人现场交流”；模型与演示预设保留自动，勾选“保留原片画质”，点“开始识别与复核”。视频默认分析起始8秒，4K原片会更慢；初次可把时长改为1秒。默认用大图看检测结果，需要时切左右对照；原图和原尺寸PNG可单独下载。单人首帧帽分0.9105，双人首帧两帽0.9366/0.9185，均为真实固定模型输出。检测分数与阈值说明放在“高级识别设置”。

两张高清照片也在素材库，自动推荐Constructelligence标准配置；当前原片4000×2667和5614×3733。1080p原轨道短片无缩放/重编码，旧960×540版本独立保留；选择“保留：既有远景视频”或自己上传旧片均可继续原检测。使用者可手动覆盖模型，效果随素材和配置变化。

1. 双击项目根目录 `启动施工视觉.cmd`，等待本地模型冷启动，进入 `http://127.0.0.1:8767`。以下旧素材流程使用“自己上传”；默认自动模型/预设、置信度0.40、原片画质开启。照片标准640，上传视频远景1280＋通用人员补充；素材库另按各条推荐配置。
2. 上传 `downloads/vision-samples/niosh-runway-worker.jpg`，点击“开始复核”。查看安全帽/反光衣检测框，再点“复核所选头部”；已测Qwen回答“可见工业安全帽”。
3. 上传 `downloads/vision-samples/bricklayer.jpg`，重新检测并复核头部。这张照片原检测器输出Hardhat0.855，Qwen给出“头发或头皮可见，未见工业安全帽”；页面并列显示两模型分歧。展示原图、裁剪图和原始回答，让人工核实，不把任一模型当成最终结论。
4. 下载原始检测JSON和完整证据ZIP。ZIP含原件、逐帧画面、框图、模型版本、裁剪原图、Qwen原答与SHA；区域复核不会改写原检测类别/分数。语言模型没有可报告的分类置信度。
5. 可切到“Constructelligence 对照（仍有误检）”，上传 `working-the-grinder.jpg` 并检测，勾选“显示全部14类”查看person框。已测该候选检出person，基线为零；没有头部框时页面明确无法据此判断戴帽。换模型必须重新检测，默认模型仍为SiteWatch。
6. 远景视频优先用 `.runtime/vision-media/window-hostivar-0-8.0.mp4`，保持自动预设，检测后选 `7.00s / frame 175`：两名轨道工人与红衣工人头部帽子候选可见。默认只检测起始8秒、每秒一个画面；效果针对固定样片优化。Florenc片段也可对照；更高分辨率并非对所有帧都更好，勿称为视频全程连续监测。

本演示按用户允许固定素材优化/过拟合的要求执行。此次无需训练，使用固定原模型的远景推理配置与原项目通用人员分支；两路原始预测与来源均导出。通用人员模型不输出帽子，头部类仍来自PPE模型。

讲解可用：“专用模型先找可疑区域，另一个视觉模型提供第二意见，检查人员结合原图核实；两个模型意见不同的地方也保留在证据里。”

## 必须展示的实际局限

`working-the-grinder.jpg` 在默认阈值下零检出；`bricklayer.jpg` 的裸头曾被误标为 `Hardhat`。模型还会把钻孔设备错标为挖掘机；界面默认只显示 PPE 框，全部原始类别仍保存在 JSON，可切换显示。视频中的 `NO-Safety Vest` 也可能误报，不能当作已经确认的发现。

Constructelligence在90张公开标注图上共同四类AP50为0.8034，SiteWatch为0.5888；它仍在砌砖工照片误判，因此没有通过默认替换门槛。公开集含课堂等非施工场景，未知训练重叠；AP不是水电一局现场准确率。局部模型在三张照片上的成功也不代表所有现场都可靠。

本阶段定位为AI初筛、第二意见与人工复核。样例均为有许可的公开实拍，非水电一局现场；来源见 `sitewatch/NOTICE.md`、`evidence/V06/source-materials.json`。自动法规违规、人员去重与全场安全结论未验证。

## 结束与恢复

电脑关机或重启会结束本地服务。再次演示时先双击根目录 `启动施工视觉.cmd`，等待几分钟后由脚本打开页面；直接打开浏览器收藏的127.0.0.1地址不会启动服务。本项目当前为手动启动，未在项目安装流程中注册开机自启。

关闭网页不会停止后台服务。双击 `停止施工视觉.cmd` 停止本项目CPU检测和GPU复核服务；再次启动恢复。命令行可分别使用 `python3 scripts/manage_ppe.py start --wait` 与 `python3 vision/scripts/manage.py start --wait`，status/stop同理。仅检测也可独立启动CPU；Qwen未就绪时复核按钮禁用并提供启动提示。

端口8766保留Qwen官方辅助问答页面；其通用隐患判断实测失败，不因本次局部头部复核成功而改变。V08已通过Windows cmd.exe实际执行根启动脚本，复用现有两个PID并打开页面；停止管理命令已分别实跑。区域模型冷启动恢复实测约163秒。
