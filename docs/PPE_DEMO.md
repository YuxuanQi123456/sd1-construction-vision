# 施工安全视觉演示顺序

演示入口 http://127.0.0.1:8767；关机后先运行根目录“启动施工视觉.cmd”。当前演示覆盖人员、安全帽、反光背心检测和头部第二意见，所有框与分数来自实际模型。

1. 侧栏保持“清晰演示素材”，默认“现场作业：结构施工安全监测”。自动模型为 SiteWatch，标准 640 输入，阈值 0.40；原片 1920×1080，不增强、不降低保存尺寸。
2. 点击“开始识别与复核”，等待采样完成。默认分析起始 8 秒，每秒一帧；可切换采样画面查看作业人员和防护装备。
3. 选一处清晰的安全帽框，点击“复核所选头部”。仅此时调用 GPT-6.1 Sol Max；看所选裁图、文字意见及与 YOLO 是否一致。没有 Key 时可先展示检测和导出。
4. 下载当前输入、检测框图或完整证据 ZIP。包内保留原视频、真实帧时间、原始检测、裁图和 GPT 回答。
5. 备用视频“高清近景：单人安全帽”“高清近景：双人现场交流”自动使用 Constructelligence；两张高清照片也可演示。切换素材/模型后重新识别，旧结果不会套用。

另可选择“区域复核对照：砌筑照片”，展示YOLO原始判断与GPT头部意见的区别，不改分数或裁图。

轨道两项因人帽太小、调阈值仍漏检而移出演示菜单，原文件保留在原路径，可通过“自己上传”继续测试。未训练新权重，未手改置信度；当前为固定素材配置优化。公开人物只作装备识别示例，非水电一局现场。

“25 类”是 SiteWatch 的目标标签数，含人员、防护、机械设施和车辆，不代表 25 项安全监测业务。当前重点为 PPE，未开展烟火、坠落、吊装动作或现场摄像头监控。NO-* 是模型候选；没有检测到装备不能直接判违规，统计框次数也不是去重人数。

原片保真和推理尺度分开：保存/下载为原字节或原尺寸 PNG，模型内部标准 640、远景 1280；页面随屏幕缩放。仅分析列出的采样时间，不代表视频全程。
