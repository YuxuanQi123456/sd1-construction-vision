## 人工标注与固定素材适配

本机已经生成标注包：

```text
E:\workspace\云枢\水电一局演示Demo\downloads\client-labeling-pack\
```

如果 LabelImg 在当前电脑上启动后退出，可以双击项目内的 `scripts\start_client_labeler.cmd`，用 Edge/Chrome 打开无安装的本地标注页。页面由本机服务自动读取上面的标注包，不再需要浏览器选择文件夹；在图片上拖框，右侧选择类别，松开鼠标后会自动保存到 `labels\train\`。页面支持放大、上一张/下一张、删除框和清空当前图片。

本轮人员适配只使用 `Person`（类别 ID 8），安全帽和马甲先不标。路障、栏杆、钢管不要标成 `Person`；没有人的画面保留空标签，作为误检抑制的负样本。后续补齐 `Hardhat`、`Safety Vest` 后再训练 PPE 适配权重，不覆盖当前人员权重和通用权重。

### 补充安全帽和反光衣标注（V20）

1. 打开 `http://127.0.0.1:8780/web/client-labeler.html`，按 `Ctrl+F5` 刷新。服务未启动时双击标注包里的 `启动本地标注.cmd`。
2. 从“脚手架工人施工”开始；保持“隐藏人员框”勾选、关闭“显示框名”。原145个人员框只隐藏，仍保存在标签中。
3. 选“定位已标注人员”里的一个人，点“居中放大此人”；滑块最高1000%，空格加鼠标拖动平移，按住X看无框原图。
4. 先点“安全帽 H”（ID2），只框帽子；再点“反光衣 V”（ID11），只框实际反光衣的可见区域。框线默认无填充，按屏幕1像素绘制。
5. 只有明确可见未佩戴，才选“未戴安全帽”（ID5，框头部）或“未穿反光衣”（ID7，框上身）。看不清、遮挡或只有几个像素时不硬标；可用“下一张 D”先跳过。
6. 每帧可见装备核对完后，点“本帧帽衣标完，下一张”。它单独记录完成进度；仅点击下一张不会把未检查的帧标为已完成。后续训练会再次核查标签和不确定帧。

拖框、删除、撤销均自动保存；S手动保存；切图前先完成当前保存。新增装备时保留隐藏的人员标签。保存失败会明确显示错误，不跳到下一张；发生版本冲突可先下载标签草稿，再“放弃未保存修改并重读”。`label-history/` 保留每次变更前的本地备份，不上传GitHub。不要清空标签来隐藏人员框。

当前人员模型仍只检测人员；补标不会立刻改变演示权重。用户明确告知完成后才安排帽/衣训练。
